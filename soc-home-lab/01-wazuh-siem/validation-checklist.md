# Wazuh Validation Checklist

Do not mark a checkbox complete without checking the actual environment.

- [ ] `wazuh-manager` service state confirmed.
- [ ] Windows Wazuh agent service state confirmed.
- [ ] Agent listed in `agent_control -l`.
- [ ] Agent connection state confirmed as active.
- [ ] Recent endpoint events visible in the dashboard.
- [ ] Event timestamp and timezone noted.
- [ ] Wazuh version and install method recorded.
- [ ] Sanitized text output saved, if useful.
- [ ] Any unresolved errors documented.
